How to read these

AUC measures how well a model ranks risky items above safe ones: 0.5 is a coin toss, 1.0 is perfect. Each model is tested on the newest 25% of data it never trained on.

Every score on screen lists its reasons. They come from each feature's contribution to the logistic regression (its weight times the customer's value), so staff can check the logic instead of trusting a black box.

The demo data comes from simulated customers. With real Brightloop history, press Retrain and the same code learns from it.
